# 微雪试用样机免密码配网

2026-09-11：按一人一机、固定使用场景，微雪 Voice Lab standalone 板型显式启用免密码热点。

- 首次无网络或长按 BOOT 三秒进入 AP；手机连接 XingTun-Audio-xxxx，无需热点密码。
- 仅播报“请连接设备热点，完成配网。”；配网中短按 BOOT 重播这一句。
- 原有 DNS/HTTP 配网页跳转保留；未弹出时手动访问 http://192.168.4.1。
- 用户仍需输入家庭或办公 Wi-Fi 密码；保存联网后关闭 AP，五分钟尝试旧网规则不变。
- 绑定码播报、账号校验及录音权限不变。此改动不限制后端只能绑定一台设备。
- 旧 wifi_provision/ap_password 不再读取或使用，不删除它以便回退；Wi-Fi、设备身份、客户归属均保留。
- 其他客户板默认仍使用原有独立密码。开放 AP 只提供客户配网界面，不开放工程设置。

新增语音 vl_wifi_open.ogg 文本为“请连接设备热点，完成配网。”，使用 Windows Microsoft Huihui Desktop 本地合成，转码为 16 kHz 单声道 Ogg Opus。原有密码语音保留供其他板型使用。

须实机验证：旧 NVS 升级后热点无需密码、BOOT 短按无数字播报、手机弹页/手动访问、配网成功关闭 AP、原绑定与录音仍可用。
