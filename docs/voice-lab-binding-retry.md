# 绑定重试与恢复出厂

临时绑定证明使用 `voice_lab/claim_proof` 保存到 NVS，并在发送首次申请前提交成功。断网、响应丢失或重启继续使用同一证明；它不写日志，也不出现在二维码中。客户领取后继续保存候选凭据并确认交付，成功时清除临时证明。

恢复出厂先停止连接和绑定任务。已有设备凭据时沿用解绑接口；没有设备凭据但有临时证明时，调用 `/api/v1/device-claims/cancel` 撤销未领取申请。只有收到成功回执才清除证明和网络。失败保留配置；已被客户领取的申请应先完成绑定再恢复出厂，不能通过取消申请转移归属。

联网后沿用“无线网络已连接，正在连接服务，请稍候”播报。连接初期保持黄灯，连续失败达到一分钟才显示红灯并播报一次“暂时无法连接服务”，后台仍继续重试；成功后恢复绿灯。未领取时仍通过八位绑定码完成授权。

此修复不绕过服务端五分钟有效期，也不允许用机器码替代证明清除其他申请。升级旧版时，旧版未保存的证明不能凭空恢复，需要在设备停止运行后由维护流程清理尚未领取的旧申请。
