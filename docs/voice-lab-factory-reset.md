# 解绑、换网与恢复出厂

无屏语音样机的 BOOT 在松手时判断持续时间：约 3 秒进入配网，至少 10 秒进入恢复出厂确认。确认时黄灯快闪并播报提示；20 秒内短按 K2 确认，短按 BOOT 或超时取消。录音开始、进行和收尾期间不可恢复出厂。

网页解绑后保留 Wi-Fi。服务端撤销旧凭据并关闭控制连接；设备重连时用旧凭据查询 `/api/v1/device-claims/status`，只有明确 `released` 回执才清绑定并重启。普通 403、网络超时不触发本地清除。

机身确认恢复出厂后在后台任务停止旧连接/绑定流程，持有效凭据调用 `/api/v1/device-claims/release`。收到回执后清除 Voice Lab 身份和保存的 Wi-Fi，再播报并重启；离线或失败保留配置。无身份的未注册设备可以直接清配置。服务地址恢复固件默认值，硬件 MAC 不变。

重新绑定会获得新身份；旧凭据只能查询自己的回执，不能影响新绑定。录音仍属于原账号，解绑不删除服务器上的音频或文字。

验证：ESP-IDF v6.1，ESP32-S3 无屏音频版本地构建；主机测试 67 项（2 项跳过）。BOOT 计时、播报、网页解绑和重新绑定仍需真机闭环验收。
