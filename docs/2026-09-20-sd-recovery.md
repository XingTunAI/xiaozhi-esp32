# SD 卡手动恢复

设备“检测 SD 卡”改为受保护的卸载、断电、初始化和挂载流程。录音、启动录音、停止排空或尚有归档写入时拒绝恢复；界面显示忙碌原因，不覆盖现有挂载状态。

归档维护请求暂停新扫描，扫描器在当前请求收尾后关闭目录并退出；最多等待约 5 秒取得独占存储锁。获取失败不卸载、不切断电源。归档初始化、任务创建和上传扫描都参与此锁；写入线程通过 active/finishing 生命周期保护，只有归档完全停止后才允许维护。

仅操作 SDMMC slot 0。使用 IDF 默认的带 slot 参数反初始化回调，禁止调用清除所有 slot 的 sdmmc_host_deinit。当前 IDF 的 deinit_slot 会尝试释放共用控制器；C6 slot 1 仍注册时底层报 INVALID_STATE，兼容层转为成功。这条日志不等同于 TF slot 清理失败。

释放卡槽后，使用板级已有 GPIO45 低有效电源开关，关断 200 ms、上电等待 100 ms。首次按 20 MHz 默认上限挂载；失败后重新断电，最多再试一次，降到 400 kHz 上限。保留 format_if_mount_failed=false，不删除卡内数据。此为低速恢复策略，不能作为补传吞吐量基线。

两次失败显示初始化错误码，不将所有超时认定为未插卡。挂载成功清除归档不可用标志并恢复扫描。若 VFS 卸载失败，隔离后续重试并要求重启，避免复用可能已释放的 card 指针。此版只实现手动恢复，未承诺自动热插拔或物理电源瞬变问题已修复。

待真机验证：正常卡重复检测；拔卡检测失败再插卡恢复；补传中检测能安全收尾或拒绝；录音中检测被拒绝；恢复前后 C6 在线；已有文件及后续录音补传校验。编译和主机测试不能替代这些硬件检查。
