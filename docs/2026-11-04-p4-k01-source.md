# P4 K01 四麦音源接入

日期：2026-11-04。状态：2026-11-11 已用 IDF 6.1 编译上板，K01 MIC1 经听见完成第一段 60 秒静音录音（见文末）。

## 做了什么

把星豚自研声卡核心板 K01（ES7210 四通道 ADC，经 FFC 接 L-401 线阵或 C-401 环阵）作为第三种录音音源，与 USB 声卡、本机双麦 PDM 并列。上传、ACK、断线补传、TF 归档、录音授权全部沿用现有 Voice Lab 链路，没有新增传输逻辑。

- 接线、引脚选择和首次上电记录：voice-lab 仓库 `docs/tech/ESP32-P4-WIFI6-DEV-KIT/K01-AUDIO-BOARD-WIRING.md`。
- 引脚、I2S 格式和 ES7210 配置，照搬 2026-11-04 已在同一块板上通过的探针（voice-lab `firmware/p4-k01-probe`）。该探针的验证结果：I2C 只见 0x18/0x40，芯片 ID 正确，8 秒 TDM4 采集零错误。

| 项目 | 取值 |
|---|---|
| K01 I2C | I2C0，SDA GPIO26，SCL GPIO27；不用板载 I2C1，因为板载 ES8311 也是 0x18，会冲突 |
| 采集 | I2S2 TDM RX 主机，MCLK 20 / BCLK 21 / WS 23 / DIN 22；16 kHz，4 槽 × 16 bit；MCLK 256fs |
| 端口分工 | I2S0 = 本机 PDM，I2S1 = 板载 ES8311 播放，I2S2 = K01，三者互不抢占 |
| 输出 | 16 kHz 单声道 PCM16，每帧 20 ms，与 PDM/USB 相同 |
| 处理 | 只有原始数据：可选单颗麦，或四颗麦直接求平均。不做 AFE、AGC，也不加数字增益 |
| 播放 | 仍由板载 ES8311 播放提示音；K01 板上的 ES8311 和功放本版不使用（AMP_EN 由板上下拉保持关闭） |

ES7210 的 TDM 槽位顺序是 MIC1、MIC3、MIC2、MIC4（见 `box_audio_codec.cc`），代码按物理麦号选槽。这个映射还要用逐颗轻敲的方式核实；核实之前，阵列几何相关的结论都不能依赖它。

## 无屏运行（2026-11-11）

7 寸屏改为可选：开机时探测屏幕控制器 0x45，探测不到就以无屏方式运行（`Screen controller 0x45 not found; running headless`），使用基类的 NoDisplay；网络、听见连接和录音全部照常。需要屏幕的串口命令（`p4 employee`、`p4 account-page`、`p4 binding-button`、`p4 record-button`、`p4 ui-freeze/resume`）在无屏时只打印提示，不会崩溃。无屏时录音由听见管理端远程开启。接屏时行为与原版一致。

## K01 与 H2 USB 口互斥（2026-11-11）

双 USB Host 版为了让 FS OTG 走 H2（GPIO24/25），开机时调用 `usb_wrap_ll_phy_select(&USB_WRAP, 0)`，USB Serial/JTAG 随之改走 FSLS PHY 1，也就是 **GPIO26/27**，正好是 K01 的 I2C 脚。探针固件不装 USB Host，所以 11-04、11-11 的探针都正常；换到听见固件后，K01 在 0x40 探测超时，录音开始约 2 秒就以 `failed_to_start_recording` 结束（11-11 22:37 两次）。

修正：USB 布局在开机时按 NVS `p4_audio/source` 决定，并保持到下次重启。

| 开机时音源 | USB 布局 |
|---|---|
| K01 | 只装 HS USB-A（`peripheral_map = BIT0`），不切 PHY；USB Serial/JTAG 留在 GPIO24/25，GPIO26/27 给 K01 I2C。H2 口不可用 |
| USB / PDM | 与原版一致：HS USB-A + FS H2 |

开机日志分别为 `USB host: HS USB-A only; FS H2 off because K01 uses GPIO26/27` 和 `USB dual host: HS USB-A + FS H2 (GPIO24 D-, GPIO25 D+)`。用串口在 K01 与 USB/PDM 之间切换时，如果需要换布局，固件保存设置后打印 `USB layout must change ...; restarting in 1 s` 并自动重启；配对凭据和 Wi-Fi 都在 NVS，重启后自动重连听见。

## 选择与命令

选择保存在 NVS `p4_audio`，**从下一段录音开始生效**，不会在录音中途换源；音源初始化失败时报错，不会悄悄改用别的音源。

| 串口命令 | 作用 |
|---|---|
| `p4 audio k01` | 下一段录音使用 K01（通道和增益沿用上次设置） |
| `p4 audio k01 mic 1`…`4` | 只录这一颗麦，同时选中 K01 |
| `p4 audio k01 mean` | 四颗麦求平均，同时选中 K01 |
| `p4 audio k01 gain 30` | ES7210 PGA 设为 30 dB（0–37.5，可带一位小数），不切换音源 |
| `p4 audio usb` / `p4 audio pdm` | 切回原有音源 |
| `p4 audio status` | 显示下一段录音的音源、PDM 增益、K01 通道和增益 |

新键 `p4_audio/source`：0 = USB，1 = PDM，2 = K01；另有 `k01_mode`（0 = 平均，1–4 = 单颗麦，默认 1）和 `k01_gain`（单位 0.1 dB，默认 300）。旧键 `pdm` 继续同步写入。回滚到旧固件时，K01 会被当作 USB，不会误开 PDM。外设页“下次录音”一行会显示 `K01 MIC1` 这类 ASCII 文字，不需要重新生成字库。

开录时打印 `K01 capture started: ... PGA x dB (REG43-46=..)`，回读的低 4 位是实际增益档（0 = 0 dB … 10 = 30 dB，14 = 37.5 dB），高位 `0x10` 是该路使能。录音期间，每秒打印一行 `P4K01`：四颗麦各自的均方值和峰值、读错误数、DMA 溢出数，用来做逐颗轻敲测试和排查故障。

设备上报的 `audioFrontend` 改为 `p4-usb-pdm-k01-selectable`，`audioFrontendFirmware` 改为 `p4-mm-afe-usb-k01raw-v1`。它们只表示设备支持哪些组合，不代表某一段录音实际用了哪个音源；实际音源要看日志里的 `K01 capture started` 和 `Next recording input`。

## 2026-11-11 第一段 K01 听见录音

- 修正 USB 布局后经 COM7 只重写应用分区（0x20000，4,416,352 字节，校验通过）。录音由管理端远程开启，run `2ef321c2-fd73-42f7-ad1e-9f18dd6abe8b`，状态 completed。
- 设备端：`K01 ready` → `K01 capture started: K01 MIC1, PGA 30.0 dB`，63 行每秒电平全部 `read_errors=0 overflow=0`，`read_fail=0`，每 50 帧收到一次入口 ACK，结束时 `audio status: completed`。
- 服务端留档 `diagnostics/dce83ce0-81ad-4f47-a2cd-b92419afcec8/ingress/device-input.wav`：16 kHz 单声道，63.04 秒，RMS 1.97 LSB（−84.4 dBFS），峰值 11 LSB（−69.5 dBFS），直流 −0.3 LSB。约一半能量在 100 Hz 以下。
- **更正**：上面这段以及之前所有 K01 数据，实际 PGA 都是 0 dB。esp_codec_dev 的 ES7210 驱动在 `enable()` 里会用一个从不更新的内部字段（默认 0 dB）重写 REG43–46，所以“先 `set_mic_gain` 再 `enable`”的增益会被覆盖。23:10 起改为先 enable 再设增益，`K01 capture started` 日志附带寄存器回读（如 37.5 dB 为 `1e`）。修正后，30 cm 外的桌面助理全音量放音在 37.5 dB 下语音约 −21 dBFS 并有削波，信噪比仍约 29 dB；默认值改回 30 dB。详细对比见 voice-lab 文档 `docs/tech/ESP32-P4-WIFI6-DEV-KIT/K01-AUDIO-BOARD-WIRING.md`。
- 仍待做：逐颗轻敲核对槽位、真人说话录音、与 ReSpeaker 等距对比。
