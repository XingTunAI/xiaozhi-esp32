# P4 双麦与 USB 音源选择

**当前状态：使用 USB 声卡，已移除双麦相关界面入口。下文按时间保留历史实现和测试过程；最新状态见 [USB 基线](2026-09-21-p4-usb-baseline.md)。**

## 实现

迁移来源：`C:/QIU/XingTunAI/voice-lab/firmware/p4-voice-terminal/main/audio.c`，以及同仓库 `docs/tech/ESP32-P4-WIFI6-DEV-KIT/2026-09-14-DUAL-PDM-PROBE.md`。

- 设置 → 存储与音频 → 选择本机双麦 / 选择 USB 声卡。选择存入 NVS `p4_audio/pdm`，下次录音生效；当前录音不会中途换源。未保存过选择的设备默认 USB，兼容现有使用方式。
- 本机双麦沿用原实验 GPIO2 CLK、GPIO3 DAT、3V3/GND。I2S0 PDM RX，16kHz、PCM16、交错双声道。没有改动原有外设引脚。
- ES8311 标准 I2S 改用 I2S1，仍使用 GPIO13/12/10/9/11，I2C GPIO7/8 不变。I2C 只用于 codec 控制；双麦不经过 ES8311。
- 移植原 MM AFE 高性能配置，双麦语音增强和降噪开启，AGC/AEC 关闭。为连续录音关闭唤醒及 VAD 门控，输出完整 16kHz mono PCM 给现有上传和 TF 归档链路。此次未迁移旧探针的业务模拟器、网络栈或单独的唤醒会话。
- 双麦采集任务按 AFE feed 块读取，独立于网络和存储。停录关闭 PDM，任务等待通知；下一段清除 AFE 输出缓存。两路原始均方电平、样本数、读取错误和 DMA 溢出计数写入 `P4Pdm` 日志。原始双声道不另行保存。
- USB 沿用现有 UAC2 采集。ES8311 保留播放。PDM 初始化失败不偷偷切换 USB，读取失败交给现有录音异常处理。
- 设备音频前端标识为 `p4-pdm-usb-selectable`，固件标识 `p4-mm-afe-usb-v1`，避免把本机双麦谎报为 XVF3800。该标识表示设备支持的组合，不表示某次录音实际选择；每段的实际来源目前需结合设备设置和日志核验。

## 后续烧录与首轮发现

用户授权烧录验证后，确认 COM32 为 ESP32-P4 v3.1。备份 `0x8000..0xffff` 关键分区和 `0x20000` 的完整 ota_0；实际分区表与构建二进制逐字节一致，OTA 活动槽为 ota_0。仅写入应用，不改 NVS、分区表、OTA 元数据及资源区；esptool 写后哈希校验成功。

新增物理串口命令 `p4 audio pdm`、`p4 audio usb`、`p4 audio status`，同样只改变下一段录音选择。

首版实测虽然双麦 DMA 无溢出且有云端 ACK，但 AFE FEED 缓冲区多次满，不能作为通过证据。原因是每个 20ms 输出请求都调用 Start 并争用 feeder 持有的 64ms I2S 读取锁。修复为运行状态原子快路径，仅首次初始化/启动和停录持锁；重新构建和烧录后复测。最终运行日志显示 AFE 实际管线是 `SE(BSS)`，不宣称另外加载了神经网络降噪模型。

## P0 采集基线恢复

2026-09-21 经用户要求，恢复 P0 的 8×320 DMA 和每次启动后3200帧（200ms）预热丢弃；正式 PCM 回调和样本序号从预热完成后的数据开始。不删除已上传/归档的样本。预热总等待受500ms截止时间及每次100ms读取超时约束，失败则停止通道并报告错误。原始 L/R 模式不再创建AFE；仅第一次选择AFE时创建其资源。若已经运行过AFE，资源保留至重启，避免复杂的任务销毁。

这不是整机回刷旧探针：保留 IDF 6.1、网络/屏幕/SD 和100ms读取超时，以兼容现有停止与错误处理；不更改GPIO、采样格式、PDM时钟默认值和硬件高通。设备验收先设原始R、x1，不以放大后的峰值判断采集质量。现有增益档位和实验AFE入口仍保留。

限制：预热目前发生于输入任务的首次读取阶段，开始提示之后会额外等待约200ms才交付首批PCM；录音UI启动与有效PCM之间尚未加入独立预热状态。该改动旨在验证开头瞬态，中途尖峰、人声偏小、AFE失真仍需分别验收。

基线恢复版编译、87项主机测试和烧录校验通过；应用SHA256 `B9783F54203C4E28D785ACF191C8AA9403AAB55EC92264EBD63412B82CB5355F`。原始R×1短录音自检保存460160样本（28.76秒），停止后状态无中断；日志确认200ms预热完成，未创建AFE流水线，首秒增益前峰值540（此前启用瞬态首秒约32729），已捕获统计无读错或DMA溢出。环境和讲话不受控，不能据此验收人声清晰度或宣称所有中途尖峰消除。

原始 L/R 现可选择数字增益 x1 / x2 / x4（约 0 / +6 / +12 dB）。默认 x1，NVS `p4_audio/pdm_gain`；设置在下一次录音锁定。外设页的 `PDM x1 / x2 / x4` 按钮循环选择，状态行显示下次有效增益。USB 和 AFE 不受此增益影响。串口 `p4 audio gain 1|2|4` 可直接选择。

采用 PCM16 饱和运算防止放大溢出翻转符号，并不等于消除削波。每秒串口报告原始均方值、峰值、放大导致的削波样本数和 DMA 溢出累计数。该版本未加入 AGC、降噪或高通，便于单独评估增益效果；增益也会放大噪声。

外设设置新增 `PDM L`（slot 0）、`PDM R`（slot 1）、`PDM AFE`（双麦增强）。L/R 是声道标记，尚未标定对应实物麦克风的位置。选择后仅下一次录音生效，不切换正在录制的声音。

新 NVS 键 `p4_audio/pdm_mode`：0 原始 slot 0，1 原始 slot 1，2 AFE；缺省为 0。原有 `pdm` 音源选择保留。原始模式直接从交错双声道抽取一路 PCM16，不做混音、增益或 AFE 处理；部分读取保留到下一次读取，凑齐 320 帧再交付。

串口命令：`p4 audio left`、`p4 audio right`、`p4 audio afe`；`p4 audio status` 查看下次录音模式。USB 路径不变。

该改动用于定位噪声，不代表已修复噪声或通过人声质量验收。需同一句话分别录制三种模式，回放并核对 ASR。
