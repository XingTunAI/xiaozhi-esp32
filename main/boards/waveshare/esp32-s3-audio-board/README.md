## Voice Lab 自助交付操作（独立模式）

以下操作仅在 `CONFIG_VOICE_LAB_STANDALONE_MODE=y` 时启用。普通小智模式保留原按键与灯效。
这是本次固件定义，**尚需在样机验证后作为客户手册定稿**；按键位置、USB 供电口与灯光照片应以实物补充。

| 按键操作 | 触发条件 | 固件动作 |
| --- | --- | --- |
| K1 短按 | 正常运行 | 喇叭音量增加 10，最高 100；不改变录音采集增益 |
| K3 短按 | 正常运行 | 喇叭音量减少 10，最低 0；不改变录音采集增益 |
| K2 短按 | 已联网、未录音 | 向 Voice Lab 服务请求开始；只有服务端授权并确认后才采集，未确认不亮蓝色录音灯 |
| K2 或 BOOT 短按 | Voice Lab 正在录音 | 结束当前采集并收尾；网页结果整理可能仍在继续 |
| K2 或 BOOT 长按约 3 秒 | 正常启动、待机、联网中、录音或播放中 | 停止录音与播放，进入重新配网；保留设备身份、绑定及正式服务配置，也不删除已保存的 Wi-Fi |
| BOOT 短按 | 待机或未在 Voice Lab 录音 | 提示到 Voice Lab 网页开始录音，作为兼容辅助键 |
| BOOT 短按 | 启动阶段 | 保留启动期进入配网的快捷操作 |
| RESET | 任何状态 | 硬件复位，行为保持不变；不作为正常结束录音的方式 |
| K2 / BOOT 再次操作 | 已在配网模式 | 重播配网提示与密码，不重复启动配网；长按松手不会触发短按录音 |

升级与不可恢复错误状态不会启动重新配网。按键回调只排队操作；录音尾部发送、开始请求、断连由单个后台工作任务处理，避免卡住按键或应用主循环。
按 K2 是向服务端发送请求，不会绕过客户归属、独占或授权检查。若服务端未支持该请求或 10 秒内未确认，设备提示失败；仍可在网页发起测试。

### 现有按键接线依据

[官方 1.1 原理图](https://files.waveshare.com/wiki/ESP32-S3-AUDIO-Board/ESP32-S3-AUDIO-Board_1.1.pdf) 与
[官方出厂例程](https://files.waveshare.net/wiki/ESP32-S3-AUDIO-Board/ESP32-S3-AUDIO-Board-Demo.zip)
确认板上已有三个自定义键及 BOOT、RESET，共五个按键：

| 实物键 | 原理图网络 | 电气行为 |
| --- | --- | --- |
| K1 / Key1 | Extend_IO9，TCA9555 P11 | R7 上拉，按下接地 |
| K2 / Key2 | Extend_IO10，TCA9555 P12 | R44 上拉，按下接地 |
| K3 / Key3 | Extend_IO11，TCA9555 P13 | R77 上拉，按下接地 |
| BOOT / Key4 | GPIO0 | 原有低有效启动键 |
| RESET / Key5 | RESET / CHIP_PU | 硬件复位 |

本次只启用已有键，不增加硬件、不重分配 GPIO。独立任务每 20 毫秒一次性读取三个输入，连续三次样本去抖。
I2C 出错或扫描停顿会取消当次手势，稳定松开后重新接受操作，防止通信故障被误判为开始录音或长按配网。
开机时已按住的 K1/K2/K3 也须先松开再按，RESET 与 BOOT 上电下载行为保持原样。

### 无屏使用

音频交付版本 `CONFIG_VOICE_LAB_AUDIO_ONLY=y` 不需要外接屏幕或摄像头，使用板载喇叭播报关键状态并结合灯环反馈。
配网时会播报本机临时热点密码；开始请求、确认开始、停止和异常均应按真机播报验收。
喇叭调到 0 会听不到播报，按 K1 恢复音量后再操作；录音灯仍保持可见。

重新配网时，手机连接本机 `XingTun-Audio-XXXX` 热点，输入本机播报的临时密码，再打开本机配网页；有屏版本同时以屏幕提示为准。
手机提示“无互联网”时保持连接，保存家庭或办公 Wi-Fi 后再切回可上网的网络，返回 Voice Lab 网页。
热点后缀、密码播报、手动入口和自动弹页行为均须在交付样机上核对，不能照搬其他型号的客户说明。

| 灯环定义 | 对应状态 |
| --- | --- |
| 黄色慢闪 | 等待手机配网 |
| 黄色流动 | 首次连接 Wi-Fi、连接服务、等待开始录音确认或已停止采集正在收尾 |
| 低亮绿色常亮 | Voice Lab 服务就绪、未录音 |
| 蓝色常亮 | Voice Lab 正在录音 |
| 红色慢闪 | Wi-Fi 中断、服务异常或设备不可恢复错误 |

录音状态由 Voice Lab 采集状态决定，不使用语音助手的 listening/VAD 状态冒充。
状态灯使用固定非零亮度，普通亮度设置不会熄灭录音提示；本次不增加装饰灯开关。
程序只在状态切换时更新灯效，防止反复重启动画；断网重试期间保留异常提示。

**通道顺序：** [官方出厂例程](https://files.waveshare.net/wiki/ESP32-S3-AUDIO-Board/ESP32-S3-AUDIO-Board-Demo.zip)
中 `ESP-IDF/factory_01/main/rgb_led_driver/rgb_led_driver.c` 使用
`LED_STRIP_COLOR_COMPONENT_FMT_RGB`，本板独立模式已显式采用 RGB；其他板仍默认 GRB。
首轮实测待机变成红色是红绿通道互换；2026-09-09 按用户原有习惯调整为绿色待机、蓝色录音、红色错误。
修正版已烧录，用户现场确认联网后绿色常亮；日志同时确认为在线、待机、未录音。初次扫描不再误闪红色异常灯。
状态切换串口日志同时记录指示状态、实际录音标志和控制连接状态，避免只根据灯色推断采集。
最终五种灯效仍需补拍实物图例，录音和异常场景分别验收。

### 真机验收

- 无网络、云服务不可达、待机和录音时分别长按 3 秒，验证能重新配网且设备归属与服务参数保留。
- 验证一次长按只有一次配网动作，松手不误触短按；录音停录未完成时长按，仍会在停录后进入配网。
- K1/K3 逐次按压验证音量增加/减少且不影响麦克风增益；确认按键丝印与原理图顺序一致。
- K2 待机短按应只发送开始请求；断网、未分配客户、拒绝或超时不能采集；服务端确认后才播报开始并亮蓝灯。
- 网页或 K2 请求开始录音后，分别用 K2、BOOT 短按停止，对照网页状态与尾部音频；开始/停止快速重复按压不应新建重复测试。
- 原理图与官方产品页标注七颗 RGB 灯，独立版本已按七颗驱动；逐颗核对实际点亮与颜色，普通构建保持原灯配置。
- 逐一拍摄五种灯效；模拟断网、服务连接失败与恢复，确认异常不会误显示为待机。
- 在录音中更改屏幕或普通灯光亮度、播放提示音，确认蓝色录音提示仍可辨认。
- 回归普通小智构建的短按对话操作，并验证开机按住 BOOT 不会被误当成运行期长按（ESP32 启动下载模式取决于硬件上电时按键电平）。
